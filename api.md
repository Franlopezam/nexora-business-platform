# API

The interactive API reference is available at `/docs` while the application is running.

Main endpoints:

- `POST /api/auth/login`
- `GET /api/auth/me`
- `POST /api/auth/users`
- `GET /api/products`
- `POST /api/products`
- `DELETE /api/products/{id}`
- `GET /api/customers`
- `POST /api/customers`
- `GET /api/sales`
- `POST /api/sales`
- `GET /api/inventory`
- `POST /api/inventory`
- `GET /api/dashboard/summary`
- `GET /api/reports/sales.csv`
- `GET /api/audit`
